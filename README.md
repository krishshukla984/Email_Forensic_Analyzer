# Email_Forensic_Analyzer
AI-powered email threat detection and forensic intelligence platform that analyzes suspicious emails, verifies headers and authentication, detects phishing/BEC threats, extracts IOCs, performs GeoIP and infrastructure analysis, correlates campaigns, and generates explainable forensic reports with evidence timelines. 

There are a lot of things we're trying to integrate with it but it takes time, and we're working over it, we'll update the file content,codes,etc. and notify you, you may download the new package and try it.
